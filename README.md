# Panthera: Leopard Vision

Build a premium cinematic wildlife website called “PANTHERA” for AI-powered individual leopard identification.

USE THE UPLOADED VIDEO AS THE MAIN HERO/HOME-PAGE VISUAL and use ALL uploaded leopard images throughout the website as supporting visual assets. Do not replace them with cartoon/illustrated/obviously AI-looking imagery.

CORE VISUAL STYLE:

Real wildlife documentary + luxury editorial website + scientific AI.

Everything should feel like real photography: realistic leopard fur, natural rosette patterns, jungle leaves, branches, sunlight, shadows, mist and depth.

Use deep forest greens, natural browns, black shadows and warm sunlight with elegant white/cream typography.

Avoid neon cyberpunk styling and generic AI-dashboard designs.

HOME PAGE:

Use the uploaded wildlife video full-screen as the hero background.

The video should cover the entire viewport and create the feeling of entering a real jungle. If the video contains the leopard emerging through foliage, preserve that composition and make it the main visual focus.

Add a subtle dark overlay so text remains readable.

Navigation:

PANTHERA®

Home | Vision AI | IVP System | Research | Reach Us

Right: “Begin Journey”

Hero text:

“Leopard Identification with AI”

Subtitle:

“Recognizing individual leopards through their unique rosette patterns.”

Primary button:

“Begin Journey”

Add subtle cinematic entrance animations: fade-in, slow scale/parallax and staggered text. Do not make the animation excessive.

The overall homepage should feel like a wildlife documentary opening scene.

Clicking “Begin Journey” opens a dedicated leopard identification page.

Keep it visually immersive rather than looking like a normal admin dashboard.

The real backend, AI model, database and image-processing pipeline will be connected later. For this version, build the complete polished UI and use realistic mock data.

IMPORTANT:

The uploaded VIDEO is the primary visual asset for the HOME PAGE.

Use the uploaded IMAGES throughout the other pages.

Do not unnecessarily duplicate the same image.

Keep the leopard and environment photorealistic.

Make the website feel like a real wildlife research/conservation platform, not a template.

Make the website responsive, polished and presentation-ready.

Use smooth modern animations and transitions, but prioritize realism and performance.
